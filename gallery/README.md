# Organ overview previews

These JPEG previews show the complete field of view of the ten organ overview images, without cropping, and have a 2560-pixel long edge for browsing. The original full-resolution images remain unchanged in the [data-v1.0 release](https://github.com/forest1997/mouse-organs-dffoct-raw-data/releases/tag/data-v1.0).

See the [main README gallery](../README.md#organ-overview-gallery) for the embedded images and direct links to each original image.
